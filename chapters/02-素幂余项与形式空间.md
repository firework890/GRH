## 2. 素幂余项与形式空间

*（原文第 4 页）*

设 q0 是 18480 的一个正倍数，d 是一个满足 d ≡ q0/2 − 1 (mod q0) 的素数。于是 d ≡ 7 (mod 8)，且 d 与 q0 互素。事实上，(q0/2 − 1)2 ≡ 1 (mod q0)，且 8 | q0/2。记 K = ℚ(√−d)，χd(n) = (n/d)，其中 Legendre 符号在 d 的倍数处按零延拓。对 q = 1 或 q = q0，令 λq(n) = 1n≡1 (q) Λ(n)(1 − χd(n))。

这里 Λ 是 von Mangoldt 函数。我们使用整函数

L♮(s, ψ) = (s − 1)L(s, ψ)（ψ 为主特征），  L♮(s, ψ) = L(s, ψ)（ψ 为非主特征）

对固定的 q、d，置

Gq(s) = (1/φ(q)) [ Σψ mod q ( ((L♮)′(s, ψχd))/(L♮(s, ψχd)) − ((L♮)′(s, ψ))/(L♮(s, ψ)) ) − 1 ]，  cq = Gq(1).  (1)

乘积 ψχd 是模 qd 的一个特征。Dirichlet 在 1 处的非消没性，连同主特征情形下的单极点，保证所出现的对数导数在该处正则。对 y ≥ 1，余项定义为

Rq(y) = Σn≤y λq(n)(1/n − 1/y) − (log y)/φ(q) − cq.  (2)

下面描述余体积比较所需的数据。固定 q0、d。三个实尺度 x、x1、b > 1 与整数 m 满足

(log b)100 ≤ x，  x10^6 ≤ x1，  x110^6 ≤ b，  √x ≤ m ≤ 2√x.  (3)

若 m = 2u，置 s = 22^u，N1 = q02 s3⌊log₃ s⌋+5，E = K(ζN_1)，其中 ζN_1 是一个本原根。延拓 K 的一个固定嵌入的复嵌入给出 E 的无限位集合 Φ 的编号；记 f = |Φ|。由于 d ∤ N1，K 与 ℚ(ζN_1) 在 ℚ 上线性无交，而 Φ 通过作用在 ζN_1 上与 (ℤ/N1ℤ)× 等同。置 A = {τ ∈ Φ : τ ≡ 1 mod q0}。到 (ℤ/q0ℤ)× 的归约是满射，因此 f = φ(q0)|A|。这批数据包含类 −1 mod q0 中一个非空的位集合 B，并满足 |A| ≤ |B| log b。

设 a 是 N1 的不小于 xb 的最小倍数。对 σ ∈ Φ 定义名义阶

w(σ) = a/x（σ ∈ B），  w(σ) = a/x1（σ ∉ B）。

在 Φ 的标号中，一个与 N1 互素的整数表示它所在的单位类，一个不与 N1 互素的整数表示单位类。把这个标号记为 [n]。对 u > 0，置

P(u, τ) = Σn≤a Λ(n)(1 − χd(n)) (u/n − w([−n]τ))+，  z+ = max(z, 0).

每个整除 N1 的素数在 K 中分裂，因此满足 Λ(n)(1 − χd(n)) ≠ 0 的项必有 (n, N1) = 1。为看出分裂性，置 c = (1 + √−d)/2，其范数为 (d + 1)/4。整除 N1 的素数整除这个范数，而 (c) + (c̄) = OK。若一个惰性素数整除 (c)，它也会整除 (c̄)。又因 K 的判别式为 −d，没有整除 N1 的素数分歧。

设 c1 表示 q = 1 时的 cq。在 a 阶导数之和中的公共减项为

P* = a log a + c1 − (1/f) Σσ∈Φ log w(σ)，  R = Στ∈A P(a, τ) − P*.

下面是后文需要的精确分布恒等式。

**引理 2.1.** 取如上定义的素幂权，则有

R = a ( |B| ( Rq_0(x) − Rq_0(x1) ) + |A| R1(x1) ).  (4)

证明. 对每个有贡献的 n，乘以 [−n] 把 A 双射地送到 q0 之上 −n 所属的那个剩余类。当 n ≡ 1 mod q0 时，有 |B| 个 τ ∈ A 使 [−n]τ 属于 B；在其余情形一个也没有。对 y = x、x1，当 n ≤ y 时 (a/n − a/y)+ = a(1/n − 1/y)，当 n > y 时贡献为零。由于 x ≤ x1 ≤ b ≤ a，对两种权都可以在 a 处去掉截断。于是

a−1 Στ∈A P(a, τ) = |A| Σn≤x_1 λ1(n)(1/n − 1/x1) + |B| Σn≤x λq_0(n)(1/n − 1/x) − |B| Σn≤x_1 λq_0(n)(1/n − 1/x1).

右端的对数项与常数项为

|A|(log x1 + c1) + |B| log x − (log x1)/φ(q0).

由 w 的定义以及 f = |A|φ(q0)，这两部分等于 |A|P*/a。□

### 2.1 余体积与指数

### 2.2 记号与约定

对 q = 1 或 q = q0，Rq(y) 表示 (2) 中的磨光素幂余项。对主特征 ψ 记 L♮(s, ψ) = (s−1)L(s, ψ)，其余情形记 L♮(s, ψ) = L(s, ψ)。余体积比较在 x 与 x1 处计算余项，其中 log x1 = xε/6，log b = xε。这里 b 是尺度参数，而 x 趋于无穷，q0、d、ε 固定。

在 K(g) 处的主水平空间 V 上，中心幂等元 e0 选出 W = e0V。复合 Θϑ 在第 j 个提升中使用 ϑj，所用的水平由 ϑ 的原支集规定。第 5 节的 Haar 测度使有限格稳定化子具有体积 1，并在实位处采用紧对偶归一化。商空间在有理点上使用计数测度。一个稳定化子阶为 ac 的定类具有类求和权 1/ac。在定义 Θϑ 的链中，每个 theta 积分都除以其源水平的体积。在系数位 (ℓ, ι) 处，我们把 ι 看作嵌入 ℂ ↪ ℂℓ，并使用 |ℓ|ℓ = ℓ−1 与 vℓ(ℓ) = 1。对 ℚℓ 的有限扩张的整数环 O，lengthO 表示通常的 O-模长度，而 lenℓ = lengthO/e(O/ℤℓ)。于是 O/ℓO 的归一化长度等于 1。格 Lϑ,ι 由 ι 处搬运来的 Weyl 格定义，而 Vσ(y) 是把 σ 作用到无扭提升的类值坐标上之后，这些提升的余体积平方。共同主项是 H，误差容限是 Bcov。在命题 3.3 中，Vup 是假设 Vσ(y) ≤ eV_up（对每个 σ）中的那个指数，δ 是 (5) 的指数界。

我们用粗体表示 ℚ、ℂ，用黑板体表示阿代尔环 𝔸，用花体字母如 O、L 表示整数环与格，用 Fraktur 字母如 𝔭 表示理想。tr、ord、length 这类算子用正体。
