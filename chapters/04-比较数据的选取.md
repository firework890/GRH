## 4. 比较数据的选取

*（原文第 14 页）*

固定 q0、d、ε 如命题 3.1。本节中关于 x 的一切阈值都可以依赖于这三个数。置 log b = xε，log x1 = xε/6。取 m 与 r 分别为不小于 x1/2 与 x5 的最小 2 的幂与 3 的幂。对大的 x，这些选取满足 (3)、(106 log x)2 ≤ log x1 以及 6 log log x1 = log log b。最后一个量增长得超过任何只依赖于 q0、d 的常数。取 s = 22^log₂ m，c = ⌊log₃ s⌋ + 5，则有

s ≤ 32 log x，  x11 ≤ 2s ≤ 22^(2x^11)，  |A| = 2s·3c ≤ 243 s 2s.

|A| 的公式是两个 Euler 函数值之商，这里用到 2, 3 | q0。

### 4.1 较大阶的位集合

记 φ: (ℤ/N1ℤ)× → (ℤ/2sℤ)× 为归约映射。我们在类 −1 mod q03c 中选取 B，使 |B| ≥ |A|/log b，并具有下述性质：对 σ, τ, ρ ∈ B 与 0 < i < j ≤ 324s，

φ(τ/σ)j = φ(ρ/σ)i ⟹ φ(τ/σ) = 1.  (15)

置 u = 1 + q03c，它是模 N1 的一个单位。令 v = v₂(q0)，则 v ≥ 2，且对 h ≥ 0 有 v₂(u2^h − 1) = v + h。每平方一次，因子 u2^h + 1 的赋值都是 1。由于 φ(u) 的阶是 2 的幂，对大的 x 该阶为 2s−v。取一个整数 n > 264/ε，置 J0 = 324s，并取满足 Mn ≤ 2s/log x1 的最大 2 的幂 M。对大的 x 有 M ≥ 2，且

2s/(2n log x1) < Mn ≤ 2s/log x1，  (J0M)n ≤ 2s−v.

事实上，2vJ0n/log x1 → 0。在 n 个位置取值 0, …, M − 1 的 Mn 个数字向量中，存在一个至少含 Mn/(nM2) 个向量的集合 S，它们具有共同的平方 Euclidean 范数；这是因为平方范数只取 0 到 n(M − 1)2 之间的整数值。对 a ∈ S 配上类 −u[a]，其中 [a] = Σh=0n−1 ah(J0M)h。令 B 由这些类组成。它们的指数低于 φ(u) 的阶，因此这些类互不相同，φ 在 B 上是单射。对三个向量 a, b′, c′ ∈ S，(15) 中的等式给出

j[b′] ≡ i[c′] + (j − i)[a] (mod 2s−v).

两端都小于 (J0M)n，且各位数字都小于 J0M，于是 b′ = (i/j)c′ + (1 − i/j)a。由平方 Euclidean 范数的严格凸性得 a = b′ = c′。最后，

|B| ≥ (Mn)/(nM2) > (2s)/(2n n xε/6 (22^(2x^11))2/n).

指数 ε/6 + 222/n 小于 ε/4。与 |A| ≤ 243s2s 相比较，即知所需的基数对大的 x 成立。

### 4.2 标记素数与水平

置 Mω = (q0d)s+6，Q = Mω2。由于 2, 3 | q0 且 c ≤ s + 5，有 N1d | Mω。对大的 x，每个满足 U ≥ 10 log b 的区间 (eU, eU+1] 中都含有一个 ≡ 1 mod Q 的素数。事实上 Q = xO_q0,d(1)，故可固定 A0 使 Q ≤ UA_0 在整个范围内成立。把两个 Siegel–Walfisz 估计 [28, 推论 11.19] 相减，得到该区间内加权素幂之和为

(e − 1) eU/φ(Q) + OA_0( eU e−c_0√U )，  c0 > 0.

真素幂的权为 O(e(U+1)/2(1 + U)2)，这是对每个指数分别计算可能的底数得到的。在 U ≥ 10 log b 上一致地，这两个误差都是 o(eU/φ(Q))。

在左端点（对数尺度上）为 10 log b + 2i、0 ≤ i ≤ |Cl(K)| 的这些互不相交的区间中各取一个这样的素数，共 |Cl(K)| + 1 个。对大的 x，它们落在 [b10, b11] 内。它们在 E 中完全分裂：事实上 E ⊂ ℚ(ζN_1d)，而这些素数模 N1d 的类是 1。至于域的包含关系，二次 Gauss 和 τ = Σa mod d χd(a)ζda 满足 τ̄ = −τ 与 |τ|2 = d；第一个恒等式由把 a 换成 −a 得到，第二个由对两个非零剩余之比的求和得到。

对每个素数选一个 K 中在其之上的素理想。其中两个，设为 g0、g1 之上的 𝔭0、𝔭1，具有相同的理想类。于是存在 K 中的整数 πg 使 𝔭0𝔭1 = (πg)，且 πgπ̄g = g0g1。整除 πg 且位于 gi 之上的 E 的素数，在每个共轭对中各给出一个素数。对每个 i 有 f 个这样的素数，其剩余域的基数为 gi。

ℚ(ζN_1d) 的根判别式至多为 N1d。事实上，把 TN_1d − 1 的分圆分解在一个本原根处求导，可看出 Φ′N_1d(ζN_1d) 在分圆序中整除 N1d；取范数即得该序判别式的界。由判别式的塔公式得 log rdE = Oq0,d(log x)。由于 a = xb + O(N1) 且 log x1 = o(log b)，对 σ 一致地有 log w(σ) = (1 + o(1))log b。又有

(20 − o(1)) log b ≤ G ≤ (22 + o(1)) log b.

因此对大的 x 有 m log b ≤ λ ≤ 29m log b。素数的估计给出满足 λ < log N ≤ λ + 1 的 N ≡ 1 mod Q，于是

λ ≤ log N ≤ λ + √(log b)，  log N ≤ 30 m log b.

这个素数不同于 g0、g1。由于 N ≡ 1 mod 4，N 是两个整数平方之和：在 ℤ[√−1] 中取 N 与 u + √−1 的最大公因子即可，其中 u2 ≡ −1 mod N。因此可选 πN ∈ OE 使 πNπ̄N = N。在 E 的每个位于 N 之上的素数处，两个因子中有一个的赋值为 1，另一个为 0，而赋值在 N 上取 1。

### 4.3 所选水平处的阿基米德尺度

初等估计给出 f = Oq0(x12)、a ≤ 2xb，且对大的 x 有 w0(σ) ≤ 2b。对 0 < u ≤ a，

0 ≤ P(u, τ) ≤ 2u Σn≤a (Λ(n))/n ≤ 2u log a (1 + log a).

由于 log(Ω/g) = Oq0,d(log b)，还有 |J(w0(σ))| = Oq0,d(b log b)。特别地

|H| = Oq0,d( mkf b (log b)2 )，  m|R| = Oq0,d( mf a (log b)2 ).

两者之和是 o(b2)，因为 m、k、f 与 log b 都被 x 的幂界住。长射流的阿基米德尺度与来自水平的增益，通过如下组合进入：

HN = H + m Στ∈A ( J(a) − P(a, τ) ) − |A| a log N.

(1) 中 ζ 在 1 处的 Laurent 展开给出 c1 = −1 − γ + L′(1, χd)/L(1, χd)，它等于 −1 − log(Ω rdE/(2π))。于是 J(a) − P* = log(a!) − a log a + a(1 + w + G)。由凹性，log(a!) − (1/2)log a ≤ ∫1a log t dt。由于 log N ≥ λ，我们得到

HN ≤ H − mR + |A|m(1 + (1/2)log a) + a(G + (15/2)log b) ≤ H − mR + B.

最后一步中，中间的误差项是 Oq0,d(f a log b)，而 B = f a(log b)3。
