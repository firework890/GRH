## 3. 四个命题及其应用

下面的存在性陈述与比较陈述，都是关于刚刚描述的构造的联合陈述。特别地，上、下估计所涉及的映射与整模，正是存在性陈述中的数据所附带的那些。

**命题 3.**1（比较数据的存在性）. 固定如上所述的 q0、d，并取 0 < ε < 1/100。对每个充分大的实数 x，该构造给出满足 (3) 以及

log b = xε，  log x1 = xε/6，  |A| ≤ |B| log b  (6)

的数据。上面定义的秩、水平、映射的扭族以及实数都属于某一个这样的数据，且满足 (106 log x)2 ≤ log x1。它的目标维数为正，共同主项满足

|H| + m|R| ≤ b2 x−99.  (7)

**命题 3.**2（一个短提升族）. 对命题 3.1 的数据，W 中存在某个无关组元 y1, …, yn，其指数至多为 δ，并满足

n ≥ (1 − 4/b2)D，  δ ≤ 5D log(1 + b2)B，  (8)

Vσ(y) ≤ exp{ n(H − mR + Bcov) }（σ ∈ Aut(ℂ)）.  (9)

*（原文第 9 页）*

**命题 3.**3（余体积的下界）. 对同一组数据，设 y1, …, yn 在 W 中无关，且 n ≥ (1 − 4/b2)D，指数至多为 δ。若对每个 σ 都有 Vσ(y) ≤ eV_up，则

D(H − 3Bcov) ≤ Vup + 2δ.  (10)

**命题 3.**4（单侧零点判别准则）. 设 8 | q0，a0 是模 q0 的一个单位类且 a0 ≡ 7 mod 8，设 β > 1/2。假设对每个素数 d ≡ a0 mod q0，当实数 x 充分大时都有 Rq_0(x) ≤ xβ−1（其阈值可以依赖于 d）。则对每个 ψ mod q0 以及每个满足 Re ρ > β 的 ρ，都有 L♮(ρ, ψ) ≠ 0。

### 3.1 分歧素数的选取

短族在 A 的每个位置处付出代价 a log N。定义

Hrow = H + m Στ∈A ( J(a) − P(a, τ) ) − |A| a log N.

这就是第 4.3 节中的 HN。利用 log N ≥ λ 以及其中 −(15/2)log b 这一项，该计算给出 Hrow ≤ H − mR + B。同一节还表明 |H| + m|R| = o(b2)，由此得到 (7)。又由 a ≥ xb 得 b ≤ Bcov。

### 3.2 主项的相消

取命题 3.2 中的组元，置 h = H − mR + Bcov。以 Vup = nh 应用命题 3.3。由无关性得 n ≤ D，由 (7) 得 −h ≤ b2x−99。因此，即使 h < 0，组元中缺失的那些维数的代价也是有界的：

nh = Dh + (D − n)(−h) ≤ Dh + 4Dx−99.

连同指数界一起得到

D(H − 3Bcov) ≤ D(H − mR + Bcov) + 4Dx−99 + 10D log(1 + b2)B.

特别地，在尺度 (6) 下，当 x 充分大时

mR ≤ 4Bcov + 4x−99 + 10 log(1 + b2)B ≤ f a (log b)5.  (11)

对最后一个不等式，除以 Bcov。由于 a ≥ xb = x exp(xε) 且 f ≥ 1，x−99/Bcov 趋于零；而 log(1 + b2)/log b 趋于 2。所得的表达式有界，最终不超过 log b。这个计算既没有用到 R 的符号，也没有用到 H 的符号。短族在所有位置处只涉及一个有理缩放。第 6 节中的秩估计与第 8 节中的可除性估计，分别作用在它的未缩放像与缩放像上。第 11 节由有限分母界与 theta 比较推出下界比较。那里的两个整性检验，把原组元上的指数在一次 Gram 配对的每个自变量中各计入一次。

### 3.3 第二个尺度上的估计

这里 Rq 的归一化方式很关键。令 Eq(t) = Σn≤t λq(n) − t/φ(q)。对固定的 q、d 以及每个 J > 0，等差数列中的素数定理给出

Eq(t) = Oq,d,J( t (log t)−J ).  (12)

事实上，把 Siegel–Walfisz 定理 [28, 推论 11.19] 应用于模 qd 的单位类即可，而 qd 是固定的。模 q 的类为 1。在模 d 的单位上，权 1 − (a/d) 之和为 d − 1，由中国剩余定理给出主项 t/φ(q)。d 的素幂贡献 O(log t)。整除 q 的素数的素幂不落在类 1 mod q 中。对 q = 1，同样的论证只用模 d 的类。对 R 逐项积分 ∫ny t−2 dt = 1/n − 1/y，得到

Rq(y) = ∫1y Eq(t) (dt)/(t2) − cq.

对 Re s > 1，特征正交性与 Euler 乘积给出

Gq(s) = Σn≥1 λq(n)n−s − s/(φ(q)(s − 1)) = s ∫1∞ Eq(t) t−s−1 dt.

这里的减项来自唯一的主特征：对每个 ψ mod q，ψχd 都是非主特征。当实 s ↓ 1 时，取 J > 1 的 (12) 给出该积分的一个可积控制函数。于是 Gq(1) = ∫1∞ Eq(t)t−2dt 是实数，且等于 cq。取 J = B′0 + 1（B′0 > 0），得到

|Rq(y)| = | ∫y∞ Eq(t) (dt)/(t2) | = Oq,d,B′_0( (log y)−B′_0 ).  (13)

从 (4) 中解出 Rq_0(x)，并使用 (11) 与 f = φ(q0)|A|。在命题 3.1 的同一个 x1 处，这给出

Rq_0(x) ≤ φ(q0) (log b)6/m + |Rq_0(x1)| + (log b)|R1(x1)| ≤ φ(q0) x−1/2+6ε + Oq_0,d,ε(x−2).

对最后一行，在 (13) 中取 B′0ε/6 ≥ 3；此时 log x1 = xε/6，log b = xε。在因子 log b 之前的两个余项都是 O(x−3)。这个界对所需类中的每个固定 d 以及所有充分大的实数 x 都成立。关于 d 的一致性并不需要。

### 3.4 过渡到所有特征

设 χ 是模 q ≥ 1 的一个特征，置 q0 = 18480q。把 χ 诱导为模 q0 的特征 ψ。两者的 Euler 乘积相差因子 1 − χ(p)p−s，其中 p | q0，p ∤ q。由于在 Re s > 0 中 |χ(p)p−s| < 1，每个这样的因子都不为零。乘积的相等关系由 Re s > 1 亚纯延拓过去。若 Re ρ > 1/2，取 1/2 < β < min{1, Re ρ} 与 0 < ε < min{1/100, (β − 1/2)/6}。

第二个尺度上的界表明：对每个素数 d ≡ q0/2 − 1 mod q0，最终有 Rq_0(x) ≤ xβ−1。对这个剩余类应用命题 3.4 即可。

*（原文第 11 页）*

它排除 L♮(s, ψ) 在 ρ 处的零点。若 ρ = 1 而原特征为主特征，则 L 具有定理陈述中所说的极点。在所有其他相关点处，由 Euler 因子的比较知 L(ρ, χ) ≠ 0。对一个导子为 q′ 的本原特征，在带 0 < Re s < 1 中的完备化函数为

(q′/π)(s+a_χ)/2 Γ((s + aχ)/2) L(s, χ)，  (−1)a_χ = χ(−1)，  aχ ∈ {0, 1}.

完备化在这个带中与 L 有相同的零点，而函数方程把 ρ 处的零点反映为 χ 的完备化在 1 − ρ 处的零点。这一反映方程对导子为 1 的平凡本原特征也成立，此时完备化 zeta 函数的极点落在开带之外。因此，半平面上的结果排除了带内 Re s = 1/2 左侧的零点。对非本原特征，把它与其本原诱导特征相联系的 Euler 因子在整个开带中同样不为零。这就由命题 3.1–3.4 证明了定理 1.1。

### 3.5 单侧判别准则的证明

对 β ≥ 1，断言由 Re s > 1 中收敛的 Euler 乘积得到。故可设 β < 1。二次扭的作用是把对数导数之和的极点分开。我们先建立这种分离所需的非消没性。固定模数 q、实数 T0 ≥ 0 以及 1/2 < β < 1。对模 q 的任一素数单位类 d ≡ 7 mod 8，该存在类中的一个 d，使得所有 L(s, ψχd)（ψ mod q）在 Re s ≥ β、|Im s| ≤ T0 中都不为零。

为看出这一点，设 ψ0 是某个固定 ψ 的本原诱导特征。ψ0 被 χd 扭之后仍本原，因为两个导子互素。ψχd 的额外 Euler 因子在 Re s > 0 中没有零点。于是只需对有限多个 ψ0 的本原扭分别界定例外素数。对 j ∈ {0, 1} 置 gj(u) = uj e−πu^2。对一个被 1 界的序列 c，定义

θd,c(t) = Σn≥1 c(n) ( −d / nodd ) gj(nt)，

其中 nodd 是 n 的奇数部分，所出现的符号是 Jacobi 符号。在选定的那些素数 d 处，二次互反律与 (2/d) = 1 把这个符号与 χd(n) 等同起来。设 T ≥ 1，X ≤ T2，η > 0。当 t ≥ T−1 时，对平方作展开给出

Σ1≤d≤X |θd,c(t)|2 ≪η T2 t−1−2η.  (14)

事实上，当 nm 或 2nm 是平方数时，对 d 的内和用 T2，并用 gj(u) ≪η u−1/2−η。若 nm 是平方数，写 n = av2、m = aw2，二者有相同的平方自由部分 a；由此得到的关于 a、v、w 的级数收敛。若 2nm 是平方数，对 2n、m 用同样的论证，只多出一个常数。在其余情形，d-求和中的特征模 nm 的奇数部分是非主的。Pólya–Vinogradov 不等式对这个非本原特征同样给出 O(√(nm) log(2nm)) 的界 [28, 定理 9.18]。配合 gj(u) ≪η u−3/2−η，所得级数被 Oη(t−3−2η) 界住，因为 Σn,m(nm)−1−η log(2nm) < ∞。这不超过 (14) 的右端。把 (14) 的 Cauchy–Schwarz 界对 dt/√t 积分，得到

Σ1≤d≤X ∫1/T∞ |θd,c(t)| (dt)/(√t) ≪η T2+η.

*（原文第 12 页）*

取 T = (qX)1/2，令 c = ψ0 与 c = μψ0（μ 为 Möbius 函数），并取 j 与 ψ0χd 的奇偶性一致——对这些 d 而言该奇偶性是固定的。除去至多 Oq,η(X1−η/2) 个素数构成的集合之外，χ = ψ0χd 的两个积分之和至多为 T2η。

对具有这种奇偶性、导子 Q ≤ T2 的本原非主特征 χ，写 θχ(t) = Σn≥1 χ(n)gj(nt)。由 Poisson 求和得到的 theta 变换给出 |θχ(t)| = (√(Qt))−1 |θχ(1/(Qt))|。特别地，∫01/T |θχ(t)| dt/√t 被它从 1/T 到无穷的积分界住，这里用到 Q ≤ T2 与 |θχ| = |θχ̄|。

令 Gj(s) = (1/2) π−(s+j)/2 Γ((s + j)/2)。θχ 关于 ts−1dt 的 Mellin 变换是 Gj(s)L(s, χ)，这先由绝对收敛、再由 theta 变换得到。记 Mμχ(s) = ∫1/T∞ ts−1 θμχ(t) dt。在带 1/2 ≤ Re s ≤ 2 上考虑

Gj(s)2 − Gj(s) L(s, χ) Mμχ(s).

由积分的表达式，它在带内有界；在左边界上，由两个尾积分的界知其大小为 O(T4η)。在右边界上，L(s, χ)−1 的 Euler 乘积表明该差等于 Gj(s)L(s, χ) 乘以 θμχ 从 0 到 1/T 的积分。由于当 0 < t ≤ 1 时 Σn|gj(nt)| ≪ t−1，这部分贡献为 O(1/T)。三线不等式给出带内 Re s ≥ 1/2 + 9η 上的界 O(T−2η)。在 L(s, χ) 的一个零点处，该表达式等于 Gj(s)2，而后者在 1/2 ≤ Re s ≤ 1、|Im s| ≤ T0 上与零有正距离。对所有充分大的 T，这就排除了非例外素数处的这类零点。取 0 < 9η < β − 1/2。指定等差数列中的素数定理提供 qX/log X 个可用素数，多于有限多个诱导特征所对应的例外集之并。这就证明了所需的非消没性。

现在固定 L♮(s, ψ) 中某一个在 Re ρ > β 处的可能零点 ρ，取 q = q0 与 T0 = |Im ρ|，并如上选取 d。Gq、Rq 的定义对每一对这样的互素 q、d 都适用。在 Re s > 1 中，对素幂与对数项积分给出

∫1∞ Rq(x) x−s dx = (Gq(s))/s − (cq)/(s − 1).

*（原文第 13 页）*

这个表达式亚纯延拓到 Re s > 0。它在 1 处正则，因为 Gq(1) = cq。在 1 之外，它的可能极点都是单极点，留数为

( Σψ mod q ( ordz L♮(s, ψ) − ordz L♮(s, ψχd) ) ) / ( φ(q) z (1 − z) ).

这里 ordz 表示在 s = z 处的阶。在实点 z ∈ (β, 1) 处，由 d 的选取知分子非负。按命题 3.4 的假设，A(x) = xβ−1 − Rq(x) 最终非负。它的 Mellin 变换是

∫1∞ A(x) x−s dx = 1/(s − β) − (Gq(s))/s − (cq)/(s − 1).

若它的收敛横坐标是一个实点 z > β，则由 Landau 引理 [28, 引理 15.1]，该变换在 z 处有奇点。在实轴上，1 处及其右侧没有奇点。在 (β, 1) 中的一个实极点处，由前面的留数公式，留数必须是负的。从右侧趋近这样的极点会使该变换趋向负无穷，而最终非负部分的贡献非负，初始有界区间又只贡献一个有界函数。这是不可能的。因此该变换在 Re s > β 中全纯。在 ρ 处，扭的阶为零，而无扭的阶之和为正。由于 ρ ≠ 1，该公式在那里给出一个真正的极点，矛盾。命题 3.4 得证。
