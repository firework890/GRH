## 7. 提升的定表达式

短形式估计用关于定空间 Xj 的一个求和来计算定义在 Yj 上的提升。在这种改换表达式的过程中，我们保留源格、各射流的权以及在 N 处的因子。一个扭可以改变求和中的系数，但整性比较对每个扭都使用同一个源模。

### 7.1 联合最高向量

对从 Yj 到 Yj+1 的箭头，置 n = r + jt，n′ = n + t，w = wj+1(v)。记 Lj 为 Yj 在 v 处的加倍参数，并在源上使用对偶参数 −Lj。以振子真空为中心的两个参数是

Lj+1 + 2w + (n mod 2)，  −Lj − 2w − (n′ mod 2).

在参数为 R（未平移）的继承位置上，这些分量是 R + 2w 与 −R − 2w。新增位置的中心化分量是 t − 1 − 2u，0 ≤ u < t。继承分量的绝对值大于 t。R + 2w 的符号是相应两个位置上符号差符号之积。对初始区块的最后 m 个位置，这可从 R = h − 2wl(v) 时的 R + 2w = (1 + 2(j + 1 − l))h 看出。正的初始位置与更早的新增区块都有 R + 2w > t。

未加倍参数中的异号间隙至少为 h2 − (t − 1)/2，对大的 x 它超过 500(n + n′)³。设 Λ = λ + ρ − 2ρc 为最低紧权，其中 ρ 与 ρc 分别是在指定次序下正根之和的一半与正紧根之和的一半。在目标行上，从 Λ 中减去它的真空权 ⌊n/2⌋ − w，再减去异号源列的个数。源上相应的差等于匹配行上这些差的相反数。这可由分别数出每一符号在前的分量个数得到，其中新区块位于正、负中心化分量之间。新区块上的差为零。

对每一对符号差符号以及每个整数 a′ ≥ 0，取匹配的行与列上绝对差超过 a′ 的子式。这些子式之积给出两个最低紧权。事实上每一层中的行集与列集都是相应紧提升次序下的初始段，故作用一个提升极化只是重复子式的某一行或某一列；对角极化则计数层数。由于匹配使用互不相交的行列对，给定行或列中出现的所有变量都有相同的振子符号。于是定义调和条件的那些混合微分都消失。每个子式都取在互不相同的行与列上，故其积非零。我们在每个位处把这个多项式用于实 theta 数据。

### 7.2 周期恒等式中的两个投影

记 Ej 为 Yj 的实系数幂等元，采用第 6 节的约定。若 q∞ 是刚刚构造的向量、ω 是实 Weil 表示，则

置 n = r + jt，n′ = n + t，w = wj+1(v)，d = d mod 2。由于 r、t 都是奇数，Lj 上的奇偶修正为 n′，Lj+1 上的奇偶修正为 n。在 Hom(Yj, Yj+1) 的张量描述中，列变量按 x−t = JxJ̄−1 变换，其中 J 是源符号差矩阵。这个共轭作用把原来的对偶参数 −Lj/2 变成 Lj/2，其中每个符号差区块内的坐标按递减次序排列。

记 (p, q) 与 (p′, q′) 分别为小符号差与大符号差。在一个符号为 ε 的大坐标上，真空指数是 ⌊n/2⌋ − w 减去异号小坐标的个数；在一个小坐标上，它是 ⌊n′/2⌋ − w 减去异号大坐标的个数，因为逆转置把原来的环面坐标取逆。这些正是 [18, 引理 7.10] 的半符号差平移分别加上 n₀/2 与 m₀/2，其中

事实上，两种分解之差是一个酉特征，由它在紧环面上的限制决定。在小群中，中心化分量是 ci = (Lj,i + 2w + n′)/2。对第一区块的最后 m 个位置（编号 l = 1, …, m），它们是 h2 + (j + 1 − l)h。当 l ≤ j + 1 时这些位置有两个正的符号差符号，当 l ≥ j + 2 时符号差符号相反。

Li 的局部公式 [18, 引理 8.2 的证明] 现在在大群上给出 nAq(λ′)。它归一化后的权 λ′ − n₀/2 在单点上是这些 ci，其中正 ci 保持符号差、负 ci 反转符号差。它们之间是一个紧 U(t) 区块上的零权。按新坐标给它的正根排序。正 Levi 根之和的一半 ρl 在这个区块上加上 (t − 1 − 2u)/2（0 ≤ u < t），于是在指定的符号差坐标中 d = λ′ + ρl = Lj+1/2。

在原来的作用中，配对是作为对偶的小级数与指定的大级数。Howe 对偶在相反方向给出同样的配对 [17, 定理 1 与 2.1]。对任一群，设 P 为到这个配对中该级数的同型子空间上的 Hilbert 投影。多项式振子模在 P 下的像是极大同型商的一个商：事实上，与 Hilbert 重复度空间中的向量作缩并，给出到这个级数的交织映射，它们能分离这个像中的点。由 Howe 对偶，这个商对两个紧群都是容许的，且长度为有限。

不变的正内积通过在有限维紧同型空间上取正交补来分裂每个子模。因此每个不可约求和项在另一群上都有所述的配对伴侣。Schur 正交性把系数幂等元给出为到该级数每个拷贝中所选直线上的投影。事实上，对 π 中单位向量 e 的幂等元 E，卷积 E ∗ δg ∗ E 等于 ⟨π(g)e, e⟩E。于是在一个酉表示中，像里的任何单位向量都以这个系数生成 π 的一个拷贝。把该幂等元作用于 q∞ 保持伴侣的紧最高权；由构造，这就是最低紧型的权，而它在伴侣级数中的重数为 1。因此另一个幂等元固定这个向量。这就双向证明了 (25)。

我们给出插入这两个幂等元的收敛性论证。在 Schrödinger 实现中，可以使用单位 Gauss 函数相对于其全部 Heisenberg 平移的系数的范数，并在相空间上积分。逆系数变换在这个范数下还原该向量。特别地，theta 和对此是连续的：取逆之后，平移真空在有理格上绝对值的和，在其阿代尔商上一致有界。这个界来自有限位处的紧支集，以及把实 Gauss 函数在所得到格的平移上求和。

在一个维数为 D 的实 Schrödinger 空间中，实辛变换 S 关于这个范数的算子范数至多为 C‖S‖D/2。计算时使用成倒数对的奇异值 si、si−1。逆系数变换与 Heisenberg 协变性把这个范数界在变换后 Gauss 窗的范数之积以内。在一个坐标中，作两次 Gauss 积分后，Gauss 系数积分获得因子 ((si + si−1)/2)1/2。这就给出所断言的界。在我们的 Hom 空间中 D = nn′，而底层张量作用在两个实群上的范数至多为 ‖g‖‖h‖。因此每次插入的代价至多是其系数的 nn′ 阶范数矩。由衰减界 (139)，这些矩存在。这里对大的 x，间隙超过 500(n + n′)³ + 2nn′ + 8(n + n′)²：在平移后的表中，第一个区块携带分离的阶 wl，新增区块只有正号，而异号之间的间隙有下界 h2/2。

在 Gauss 范数下的收敛性，使 Hilbert 范数下的等式在此也成立。在任何固定的有限水平处，取有限多个有限阿代尔代表元以及相应算术商的实 Siegel 集。同样的范数界于是使核在每个群上于这些集合中至多按多项式增长，而关于一个实变量的乘法满足前面的矩估计。源上的速降性足以使卷积与 theta 积分可交换。

具体地，在提升中作替换 g ↦ gz−1（其中 f = R(Ej)f）会对其实向量插入 ω(E∨j)。目标上的右卷积插入 ω(Ej+1)。等式 (25) 证明目标被目标幂等元重现。

在固定有限水平处，用这个幂等元作卷积会产生速降的尖形式——即使是在还不知其有界性之前就把它作用到收敛的 theta 积分上。先把该积分的结果作为目标商上的函数，按其绝对值作截断。它的卷积平方可积，且真常数项为零。事实上，展开单幂商，可用在相应实单幂根上的 ∫REj+1(aub)du 表示卷积核的每个常数项。这些积分为零，因为这个离散级数系数在包络代数的中心下是有限的，并且属于 Harish–Chandra Schwartz 空间；因此它的左、右平移的真常数项为零 [15, 定理 9.1, 第 48 页]。

对一个有界函数与一个可积系数，这个展开是绝对的。在固定的有限水平处只有有限多个实算术商。在每一个上，固定无穷小特征的理想与固定紧型的幂等元给出一个有限维自守空间 [7, 作者笔记中的定理 8.4]；另见 [14, 定理 1]。由矩估计，当截断阈值趋于无穷时，这些卷积的值收敛到未截断的卷积。有限维函数空间对逐点收敛是闭的（在一组有限的判定集上取值即可看出）。该提升属于这个空间，并在 Siegel 集上速降 [24, 定理 2.23 与 2.24]。

在反向积分中，目标形式的共轭在同一个向量上插入 ω(Ej+1)，而 (25) 给出对偶的源型。在两个 Siegel 集上，联合范数估计是两个实范数中多项式界之积。两个形式的速降性给出二重积分的绝对收敛。于是 Fubini 给出转置关系，所用的 theta 核相同，并且在原提升上带有规定的水平体积因子。

### 7.3 一个提升下的周期

取源链的阶为 s − 1 − 2i，并取 Xj 上阶为零，使用下面描述的链映射 T。对目标阶 d′，theta 常数项由有理矩阵 Z1 按次数至少为零的矩阵取模来编号，其中元素 (b, a) 的次数为 d′(b) − deg(a)。我们使用零阶与实际目标阶。在两种求和中，保留在 deg(a) > 0、deg′(b) < deg(a) 上与 T 一致的那些项，得到同一个 Fourier 系数：在仅与这些元素对偶的加性商上取平均，特征取在 T 处。这个比较使用了 Hermite 形式的反转阶伴随。

我们回顾这两个轨道计算。在源单幂群上取平均会消去一项，除非它的特征在保持其负阶元素的子群上与 T 的特征一致。具体地说，设 v′ 支撑在阶至少为 max(1, 2 + deg(a′)) 处。若 Z1v′ 在目标 d′-阶至多 max(deg(a′), −1) 处为零，且当 d′(b) + deg(c) ≤ 0 时 (Z1)b,(a′)∨v′c = 0，则使用 v′ 与位置 a′ 的对偶向量所作的 Eichler 变换把 Z1 改变一个正阶，并把源阶至少提高 2。变化它的加性参数，由阿代尔特征的非退化性得到 [(Z*1Z1 − T*T)v′]a′ = 0。这是该平延的 Heisenberg 相位的线性系数。这里星号表示关于两个形式的伴随，而 (a′)∨ 表示把链反转。

对目标阶零，在这个检验中使用正阶源列及其对偶，得到 T 的上半列 Gram 矩阵。Z1 的这些列是无关的：在一个关系中取阶最小的非零系数，然后在其沿链的后继处使用该检验；T*Tv′ 在这个后继处的元素是该系数的非零倍数。有理 Witt 扩张现在把正阶列与 T 的正阶列对齐。

公共元素条件的稳定化子恰是目标 Bessel 群。为看出这一点，沿目标链的阶下降。高一个阶的源列在目标链中有一个非零主元，其上只有先前处理过的项。因此该稳定化子把那个目标向量模更高阶固定住。酉性提供相反的区块以及在定商上的作用。

对实际目标阶，来自正源阶的负阶元素已由公共条件固定。对其余元素，从目标链底部按阶递增的次序下降。为检验满足 deg′(b) < deg(a) ≤ 0 的 (b, a)，使用比 b 的对偶目标主元高一个阶的源列，并取 a′ = a∨。它在 Z1 下的像以 b 的对偶向量的非零倍为主元，并带有更高次的项。这些其他项与已经证明在 Z1ea 的较低目标阶中为零的元素相配。检验的两个支集条件由同样的约束成立。于是与 T*T 的恒等关系固定 Z1,ba = Tba。
