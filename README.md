## 摘要

对 theta 提升之余体积的两个界进行比较，可以得到关于素幂上一个磨光和的单侧估计，Dirichlet 广义黎曼假设即由此推出。上界来自一个几乎张成的提升族的可除性。为得到下界，我们在每个有限嵌入处选取一个扭，使其前若干次幂同时满足 Selmer 长度估计与 Hecke 值界，并在原格上比较由此得到的行列式。乘积公式在同一族上比较这两个界，而固定模数的素数定理给出零点判别所需的那一估计。
